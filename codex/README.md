# 정석biz 텍스코어 사업신청서 v{VERSION}

우리 팀 자료에서 **텍스코어(실험실창업탐색팀) 공식 사업신청서 초안과 심사 대비 패키지**를 만드는 Codex 작업 폴더입니다. 처음이라면 [사용설명서.html](사용설명서.html)을 여세요.

1. **압축 풀기:** `정석biz-TexCore-Plan-v{VERSION}.zip`을 모두 압축 해제합니다.
2. **같은 폴더 열기:** 만들어진 `정석biz-텍스코어-프로젝트` 폴더를 Codex에서 프로젝트로 엽니다.
3. **자료 넣고 말하기:** 폴더 안의 `자료넣는곳`에 한 팀의 자료(IR 덱·사업계획서·특허·시험 결과·사진·팀 이력)를 복사한 뒤 아래 문장을 보냅니다.

> 우리 팀 텍스코어 신청서 만들어줘

준비물은 로그인된 Codex, 우리 팀 자료, Chrome 또는 Edge입니다. 실행 환경(Python 패키지)은 Codex가 프로젝트 안에 준비합니다. 처음에는 인터넷과 다운로드·실행 권한 승인이 필요할 수 있습니다. 준비 중 오류가 나면 같은 대화에서 "환경 준비를 다시 확인해줘"라고 요청하세요.

**공식 hwp 양식에 자동으로 넣는 마지막 단계는 Windows + 한글(HWP)이 필요**합니다. 한글이 없는 컴퓨터(Mac 포함)에서는 본문 초안(md)·증거 도식·주입 사양까지 만들어지며, 한글이 있는 Windows에서 이 폴더를 열고 "이어서 해줘"라고 하면 양식 주입을 마칩니다.

제작과 검수 후 **`결과물/결과보기.html`**에서 최신 결과를 확인합니다. 날짜별 폴더에 사업신청서(hwp·hwpx·pdf), 심사대비_패키지.md(셀프 채점·예상 질의·확보 필요 목록·제출 체크리스트), 팀_확인사항.md, 쪽별 PNG가 모입니다. 자료에 없는 값은 `[기입 필요]`·`[확보 필요]`로 남고 팀이 채웁니다. 신청서는 초안이며 마지막 입력은 팀이 합니다.

수정할 때는 자료나 팀 답변(`02_team_answers.md`)을 `자료넣는곳`에 추가한 뒤 "4단계부터 다시 해줘", "Ⅱ-1 핵심기술 결론을 더 쉽게 써줘"처럼 말하면 됩니다. 같은 폴더와 대화에서 이어가세요.

평가표(창업탐색 아이템 20 · 핵심기술 15 · 사업화 계획 25 · 창업탐색팀 20 · 참여의지 20, 해외교육형은 영어·미국 시장 P/F)로 5인 모의심사를 거치며 목표선은 80점입니다. 자세한 양식 구조와 자료 기준은 [사용설명서](사용설명서.html)에 있습니다.

강사·기존 사용자는 [고급 안내](docs/advanced-guide.md)를 참고하세요. [짧은 시작 안내문](docs/beginner-start.md)은 교육생에게 전달하기 좋습니다.

동봉한 예시 팀 「진동지기」(`examples/`)는 모든 정보와 숫자가 교육용 가정인 작성 예시입니다. 실제 팀이 아니며, 공개 ZIP에는 참가팀의 실제 자료나 분석 결과를 넣지 않습니다.
