어떤 양식과 기준으로 만들어지나요?

공고에 첨부된 실험실창업탐색팀 사업신청서 hwp 양식(표지 포함 10쪽 이내)을 그대로 씁니다. 심사위원이 쓰는 평가표 다섯 항목에 칸마다 먼저 답하고, 답을 그림으로 증명하는 구조입니다.

  1. Ⅰ-1추진 동기와 목표참여의지·이해도 20
  2. Ⅰ-2아이템 컨셉·고객·차별성·시장창업탐색 아이템 20
  3. Ⅱ-1핵심기술 개요(세 문장 공식)핵심기술 15
  4. Ⅱ-2특허·권리관계·TRL핵심기술 15
  5. Ⅲ-1시제품 제작·검증 계획사업화 계획 25
  6. Ⅲ-2추진 일정(마일스톤·숨은 일정)사업화 계획 25
  7. Ⅲ-3애로사항사업화 계획 25
  8. Ⅳ팀 구성·경력 표창업탐색팀 20
  9. EN영문 요약(해외교육형)영어·미국 시장 P/F

칸마다 결론 박스 → □ 소제목 → 증거 그림·표 → 짧은 문단 순서로 쓰고, 문장은 80자 이내, "세계 최고" 같은 표현은 자동으로 걸러집니다. 5인 모의심사(VC·기술이전·도메인·I-Corps 인스트럭터·비전문가)가 실제 평가표로 채점하며 목표선은 80점입니다.

자료가 부족해도 시작할 수 있나요?

현재 가진 자료로 초안을 만들 수 있습니다. 자료에 없는 숫자·이름·특허번호는 만들지 않고 [기입 필요](팀만 아는 값)·[확보 필요](조사로도 못 찾은 값)로 남깁니다. 본문과 그림의 모든 숫자는 팀 자료나 공식 출처와 대조되며, 근거 없는 숫자가 있으면 다음 단계로 넘어가지 않습니다.

외부 시장 통계를 우리 팀의 성과로 바꾸지 않습니다. 최종 완료에는 팀이 확인사항을 채우는 과정이 필요하며, 완성된 모양 자체가 사업의 사실성을 증명하지는 않습니다.

처음 준비하거나 파일을 읽다가 막히면요?

필요한 Python 패키지는 Codex가 프로젝트 안에 준비합니다. 처음에는 인터넷 연결과 권한 승인이 필요할 수 있습니다. 오류가 나면 같은 대화에서 "환경 준비를 다시 확인해줘"라고 요청하세요.

오래된 hwp, 암호 파일, 스캔 문서는 내용이 일부만 읽힐 수 있습니다. Codex가 요청하면 해당 자료를 한글에서 PDF나 hwpx로 다시 저장해 넣어 주세요. 한글 양식 주입 단계에서 Codex가 "한글 프로그램을 자동으로 열어 양식에 내용을 넣는 단계"라며 승인을 요청하면 허용하세요. 다른 팀 자료는 같은 폴더에 섞지 마세요.

완성 모습의 예시를 볼 수 있나요?

진동지기(VibeGuard)는 모든 정보와 숫자가 교육용으로 만든 가상 팀입니다. 칸 구성과 표현을 살펴보는 예시이며 실제 팀의 신청서가 아닙니다.

Ⅰ. 아이템 쪽 예시Ⅱ. 핵심기술 쪽 예시경쟁 비교 도식일정 도식예시 팀 자료

공개 ZIP에는 참가팀의 실제 자료나 분석 결과를 넣지 않습니다.

강사·기존 사용자용 안내는 어디 있나요?

고급 안내에서 폴더 구조, 수동 실행, Windows 한글 주입 마무리, 쪽수 조정, 문제 해결을 확인할 수 있습니다. 글로 된 짧은 안내는 시작 안내문에 있습니다. Claude Code 플러그인 버전과 사용법 가이드는 aqualife75.github.io/jsbiz-texcore-plan에 있습니다.
