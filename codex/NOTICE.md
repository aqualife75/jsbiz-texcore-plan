# 배포와 출처 · v{VERSION}

이 패키지는 정석biz 노하우의 정부지원사업 사업계획서 작성법(예비창업패키지 작성법)과 텍스코어 핵심기술·사업화 강의안의 작성 원칙을 교육용 실행 절차로 정리한 것입니다. 텍스코어 사업 주관기관이나 평가기관의 공식 도구가 아니며, 선정을 보장하지 않습니다.

양식은 2026년도 공공기술기반 시장연계 창업탐색 지원사업(실험실창업탐색팀) 공고에 첨부된 사업신청서 서식을 기준으로 합니다. 공고 연도가 바뀌면 양식·배점·일정이 달라질 수 있으니 제출 전 그해 공고를 직접 확인해야 합니다. 평가 항목·배점·절차는 공개된 신청 안내서에 근거합니다. 모의심사 기준은 일반화된 체크리스트이며 특정 심사의 점수·의견·질문 원문은 포함하지 않습니다.

교육생은 사용 권한을 가진 한 팀의 자료만 `자료넣는곳`에 복사합니다. 원본은 수정하지 않습니다. 팀 자료의 원문을 검색사이트나 외부 서비스에 업로드하지 않으며, 근거 조사에는 공개 통계·특허 검색(KIPRIS)·기사 등 공개 정보만 사용합니다.

Python 의존성은 requirements.txt에 지정하며 각 라이브러리의 라이선스를 따릅니다(python-pptx, Pillow, olefile, python-docx, openpyxl, jsonschema, lxml, PyMuPDF, Windows에서 pywin32). PyMuPDF는 AGPL/상용 이중 라이선스이므로 이를 포함한 별도 실행파일이나 제품 재배포 시 적용 조건을 확인하세요. 한글(HWP) 양식 주입은 사용자 PC에 설치된 한글 프로그램을 COM으로 구동하며, 한글 프로그램 자체는 포함하지 않습니다. 도식 렌더와 근거 캡처는 사용자 PC의 Chrome 또는 Edge를 씁니다. Pretendard는 글꼴 이름으로 참조할 뿐 포함하지 않습니다.

동봉한 예시 팀 「진동지기(VibeGuard)」는 회사·사람·수치·특허번호가 모두 가상인 교육용 사례입니다. 실제 팀의 검수 완료 신청서가 아니며 어떤 형태로든 실제 자료로 인용하지 않습니다.

이 도구는 선정 성공이나 모든 통계·특허·이미지의 수집을 보장하지 않습니다. 코드 검사는 구조·숫자 추적·쪽수·토큰 잔존을 확인합니다. 원문이 주장을 지지하는지, 논리가 타당한지, 그림이 읽히는지는 Codex와 팀이 직접 검수해야 합니다. 조사 도구가 없으면 실제 조사하지 않은 근거를 만들지 않고 미완료로 남깁니다. 자격 요건(EL 재지원 가능 여부, 예비창업자 요건 등)은 그해 신청 안내서로 팀이 직접 확인합니다.
