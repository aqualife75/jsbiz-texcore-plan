# 모의심사 캘리브레이션(공개판)

> 공개 배포판(2026-10-27)
> **근거**: 「2026년도 공공기술기반 시장연계 창업탐색 지원사업 신청 안내서 – 실험실창업탐색팀」(이하 **안내서**)의 평가지표·선정 방식 + 신청서 심사 대비에서 반복되는 채점 경향을 일반화한 기준. 특정 심사의 점수·팀·의견·질문 원문은 싣지 않는다.
> **읽는 에이전트**: `tp-panel`(채점·의견서·심각도), `tp-finalizer`(셀프 점수표·예상 의견서). 심각도 용어는 `review_rubric.md`, 칸·슬롯 ID(`S_I2`·`I-2c` 등)는 `form_map.md`와 같다.
> 내부 캘리브레이션 자료가 있는 환경에서는 설치 시 같은 파일명으로 덮어쓴다.

## 0. 용도와 한계

- `tp-panel`이 **"합계 80점이면 선정권"** 이라는 눈높이로 채점하도록 기준점을 준다.
- 공개판이므로 실제 평가 데이터(분포·평균·팀별 점수)는 없다. 점수는 **5-1 체크리스트 + 5-3 앵커**로 정한다.
- **패널은 점수를 후하게 주지 않는다.** 증거 없는 서술형 강점에는 가점하지 않고, 두 앵커 사이에서 애매하면 낮은 쪽을 고른다.
- 하네스 목표선은 **합계 80점(선정 눈높이)** 이다. chair의 처방(`to_reach_85`)은 여유분을 두고 85점을 겨눈다.
- 실제 선정: 평가위원 점수를 산술평균해 최종점수를 내고 고득점순으로 선발한다(안내서 p.8). 평가위원회는 창업투자·기술사업화 전문가, 창업탐색교육 전문가 등 5인 내외다(안내서 p.8) → 패널 persona(vc·tlo·domain·icorps·layman)가 이 구성을 흉내 낸다.
- 해외교육형은 영어활용능력·해외시장 적합도 P/F가 따로 있고, F인 경우 평가 총점과 관계없이 미선정이다(안내서 p.8) → 6절.
- 평가지표 내용은 평가계획 수립 시 변동될 수 있다(안내서 p.8).

## 1. 채점 눈높이

### 1-1. 항목별 엄격도(정성)

| 평가항목(배점) | 엄격도 | 점수가 갈리는 지점 | 패널 운용 |
|---|---|---|---|
| 사업화 계획(25) | **가장 엄격.** 만점 대비 가장 낮게 나오기 쉽고, 고득점·저득점 신청서의 점수 차도 가장 크게 벌어진다 | 고객 검증 증거, 가격·수익모델, 단위경제, 마일스톤 형식 | 고객 검증이 "계획"뿐이면 중간 앵커 이하 |
| 창업탐색 아이템(20) | 엄격 | 고통 크기 수치, 가격이 들어간 경쟁 차별 근거, SOM 산식 | 트렌드·컨셉 서술만으로는 올리지 않는다 |
| 창업탐색팀(20) | 보통~엄격 | 공란 여부, 역할 분담, 도메인·사업 역량 | 공란('-')이 하나라도 있으면 상단 앵커 불가 |
| 참여의지·프로그램 이해도(20) | 보통 | 이미 한 고객개발 행동, 프로그램 용어·일정 반영 | 계획만 있고 실행 증거가 없으면 중간 앵커 |
| 창업탐색 핵심기술(15) | 상대적으로 관대. **바닥이 높고 점수 폭이 좁다** | 자체 IP, 조건이 붙은 정량 성능, 제3자·실환경 검증 | 차이는 이 세 가지에서만 낸다 |

- 참여의지 점수는 별도 서술보다 **"고객개발을 이미 하고 있다는 증거"**(인터뷰·현장 시험·피벗 판단 단계가 들어간 일정)와 함께 움직인다. 참여의지가 높게 나오는 신청서는 대체로 합계도 높다.
- 해외시장 적합도 P/F는 **총점과 독립**이다. 총점이 중간 이상이어도 미국 내용이 없으면 F가 나온다.

### 1-2. 합계 눈높이(하네스 해석)

| 합계 | 하네스 해석 | 전형적 모습 |
|---|---|---|
| 85 이상 | 여유 있는 통과 | 전 항목에 팀이 만든 증거(수치·n·가격·시제품 차수)가 있고, 약점은 '후속 질문형'(2-2 ◇)뿐 |
| 80~84 | 목표선(선정 눈높이) | 아이템·사업화의 핵심 증거는 있으나 표본·원가·규제 중 1~2개가 비어 있음 |
| 70대 | 근접 — 증거 보강 필요 | 구조는 갖췄지만 고객 검증 또는 가격이 "계획" 단계 |
| 70 미만 | 구조 공백 | 가격·고객 검증·경쟁 분석 중 2개 이상 없음, 팀 표 공란, 활동 목록식 일정 |

- 80점을 넘는 신청서는 많지 않다. 5인 평균이 80을 쉽게 넘으면 채점이 후한 것이므로 5-3 앵커로 다시 맞춘다.

**감점 요인 결론**
1. 고객 검증 지적은 **거의 모든 신청서**에 붙는다 — 없으면 "검증 전무", 있으면 "검증의 질"(표본·대표성·구속력)로 바뀔 뿐이다.
2. **점수를 실제로 깎는 감점(▲)**: 고객 검증 전무, 가격·수익모델 미제시, 경쟁 차별 불명확, 기술 진입장벽 낮음, 팀 정보 공란, 핵심 인력 부족.
3. **후속 질문형(◇)** 은 고득점 신청서에도 붙는다(성능 검증 조건, 양산 리스크, 규제 로드맵, 표본 크기). 모의심사에서 **major**로 다루고 critical로 올리지 않는다. 단, 규제 산업인데 언급 자체가 없으면 critical C07.

## 3. 고득점 vs 저득점 신청서의 특징

| 비교 축 | 고득점 신청서 | 저득점 신청서 | 패널이 읽는 신호 |
|---|---|---|---|
| 고통의 크기 | 문제 칸 첫 문단에 수치 + **산식** + 출처 | 규모 통계만 있고 고객의 시간·비용 손실 수치 없음, 정성 서술, 출처 미기재 | 강점 1번 문장이 "정량 입증"인가 |
| 시제품 | 차수·연도 + 검증 n·결과 수치 | "제작 예정", 자체 엔진 없음, 계획 문장 | 시제품 유무가 기술 점수 상단·하단을 가른다 |
| 현장 시험 | n·결과 수치·현장 사진 | 없음, 또는 "인터뷰 예정" | n을 적으면 다음 질문이 'n 확대'로 바뀐다(감점이 아니라 후속 질문) |
| 구매의향 | %에 n·모집 방법·지불 단위가 붙음 | 없음, 또는 %만 있고 표본·단위 불명 | %만 쓰면 오히려 질문을 부른다 |
| 가격 | 단위가 있는 가격 + 단계별 수익모델 | 제목만("구독 결합"), 정성("도입 비용 낮음") | 가격 유무가 사업화 점수를 가장 크게 가른다 |
| 경쟁표 | 실명 대안 + **가격 행** + 기능 O/X + 우리 약점 1칸 | 없음, 또는 자사 전 항목 최고점 | 자사 전승 경쟁표는 "객관성 부족" 지적을 부른다 |
| 일정 | 분기·산출물·성공 기준이 있는 마일스톤, 인터뷰·시장조사·피벗 판단 포함 | 월별 활동 목록, 수치 목표 없음, 근거 없는 "시장 1위" | 활동 목록형 일정 = 사업화 하단 앵커 |
| 팀 | 전원 이름·학위·역할·관련 실적 + 자문·협력 체계 | 공란, 이름 없이 요구 역량만, 역할 미기재 | 팀 점수 상단·하단을 가르는 1순위 |
| 정보 밀도 | 본문 + 부록(작동 원리·IP·BM) + 영문 요약 | 분량이 매우 적거나 이미지뿐이라 읽을 텍스트 없음 | 정보가 없으면 심사위원은 "없음"으로 채점한다 |
| 미국·해외 | 영문 요약에 미국 고객·시장 규모·가격·규제 | 해외 전략 없음, "글로벌 시장 검토" 한 줄 | 저득점 신청서는 P/F F와 겹치기 쉽다 |
| 숫자 일관성 | 앞뒤 단가·수량 일치 | 같은 항목의 단가가 쪽마다 다름 | numbers persona가 잡을 유형 |

**비교 결론(신청서 작성 규칙으로 변환)**
1. 문제 칸 첫 문단에 **고통 크기 수치 + 산식 + 출처**를 넣는다.
2. 시제품은 **차수·연도·검증 n·결과 수치**로 쓴다.
3. **가격을 반드시 쓰고, 경쟁표에 가격 행을 넣는다.** 경쟁표에서 자사 전 항목 최고점은 감점 신호다.
4. 일정은 활동 목록이 아니라 **분기·산출물·성공 기준이 있는 마일스톤**으로 쓴다. 인터뷰·시장조사·피벗 판단 단계를 일정에 넣는 것이 참여의지 점수와 같이 움직인다.
5. 팀 표는 이름·학위·역할·관련 실적을 채운다. "요구 역량"만 쓰거나 '-'로 비우면 팀 점수가 하단 앵커로 떨어진다.

## 4. 의견서 4칸 작성 틀과 예시

**모의 의견서 형식**: **1. 강점 / 2. 약점 / 3. 보완사항 / 4. 질의사항**, 각 칸은 "•" 개조식 한 줄 문장.

**작성 규칙**
- persona별로 각 칸 2~3줄(`review_rubric.md` 5절), chair 병합본은 각 칸 3~5줄.
- 각 줄에 **숫자 1개 이상** 또는 구체 대상(기관 유형·인증명·고객 직무)을 넣는다. 숫자는 초안에 있는 것만 인용한다.
- 약점과 보완은 짝을 이룬다(약점 "LOI 없음" → 보완 "1차 고객 n곳 인터뷰 후 LOI 확보").
- 점수대별 강점 문장 차이: 고득점은 강점이 "정량 입증·실행력 입증"(팀이 만든 증거), 저득점은 강점이 "성장하는 시장·연구 역량"처럼 **팀이 만든 증거가 아닌 외부 사실**에 머문다.

### 예시 — 진동지기(VibeGuard) (예: 80점대 가정 — 아이템 16·기술 12·사업화 20·팀 16·참여 17, 해외 P 가정)

한빛대학교 팀, 압전 진동센서 기반 소형 모터 고장 조기경보 모듈, 1차 고객은 종업원 50~300인 부품 제조사 보전팀, 해외교육형. `{ }`는 신청서의 숫자를 인용할 자리다.

1. 강점
 • 비계획 정지 1회당 손실을 "{정지 시간} × {시간당 손실액}" 산식과 출처로 제시해 보전팀의 고통 크기를 수치로 보여줌
 • 사람이 도는 휴대형 점검과 대형 설비용 상태감시 시스템 사이의 빈자리를 모듈 단가 {가격}으로 겨냥 — 경쟁표의 가격 행으로 확인됨
 • {n}차 시제품을 부품 공장 {n}곳 모터 {n}대에 설치해 {기간} 동안 고장 전 경보 {n}건을 기록, 실환경 데이터 보유
 • 신호처리 관련 출원 특허 {n}건과 권리관계 표(권리자 산학협력단, 발명자 EL)·이전 계획이 명확
2. 약점
 • 현장 시험이 한 업종·한 부하 조건에 몰려 인버터 구동·간헐 운전 모터에서의 오경보율이 확인되지 않음
 • 1차 고객의 구매 결정권자가 보전팀장인지 공장장·구매팀인지 불분명
 • 모듈 BOM·설치비·구독 원가가 없어 {가격}의 수익성이 불투명
3. 보완사항
 • 인버터 구동·간헐 운전 모터를 포함한 2차 현장 시험 계획(대상 {n}대, 기간, 성공 기준: 오경보율 {x}% 이하)
 • 보전팀장·공장장·구매 담당 인터뷰로 예산 주체와 결재 단계를 지도로 정리
 • 모듈 1대당 원가·마진과 손익분기 수량을 한 줄 산식으로 제시
 • 무선 모듈의 국내·미국 전파 인증 필요 여부와 기간을 Ⅲ-2 일정표에 반영
4. 질의사항
 • 공장 1곳이 모듈을 몇 대 이상 달아야 구독 계약이 고객에게 이득입니까?
 • 미국 보전팀은 이미 쓰는 점검 도구가 있을 텐데, 첫 미국 인터뷰 대상은 어떤 직무입니까?

## 6. 해외교육형 P/F(영어활용능력·해외시장 적합도) 판정

### 6-1. 규칙
- 해외교육형 신청팀만 해당. **영어활용능력**(실험실창업탐색팀의 영어 활용능력)과 **해외시장 적합도**(창업탐색 아이템의 해외 시장 적합도) 2개 항목을 적/부로 평가하며, **F(Fail)인 경우 평가 총점과 관계없이 미선정**(안내서 p.8).
- 해외교육형 실전교육은 美 NSF I-Corps 프로그램을 활용한 미국 현지 교육으로, 해외 인스트럭터와 함께 미국 시장 잠재고객 인터뷰를 집중 수행한다(안내서 p.10·p.11).
- 하네스 해석: 영어활용능력 = "미국 잠재고객 인터뷰를 영어로 할 수 있는가"(영문 Summary가 읽히는가), 해외시장 적합도 = "이 아이템이 미국 시장에서 성립하는가".
- 하네스 판정(모의심사 운영 규칙): persona마다 P/F를 내고, chair는 과반이 F면 F로 병합한다.

### 6-2. FAIL 패턴 4가지
1. 신청서·발표자료에 **미국 시장 언급이 0이거나 "글로벌 시장 검토" 한 줄**뿐이다.
2. 사업 구조가 **한국 고유의 제도·유통 관행·언어·특정 지역**에 묶여 있고, 그것이 없는 미국에서의 형태를 설명하지 않는다.
3. **대면·장비·연구실 의존 서비스**라 원격·현지 확장 경로가 보이지 않는다.
4. 미국 경쟁사·미국 고객·미국 규제 중 **어느 하나도 직접 다루지 않는다**.

### 6-3. 최소 통과선
- **미국 타깃 고객 1개(직무·기관 유형까지) + 미국 진출 경로·달러 결제 구조·영문 자료 중 1개가 문서에 실제로 있음.**
- 모의심사 패널은 이 둘이 없으면 P/F를 F로 판정하고 critical(C03)로 올린다. 총점이 높아도 예외 없다.

### 6-4. 통과 후에도 대비할 해외 질문
- **미국 규제·인증(분야별 예)**: 의료기기 FDA 경로(510(k)·PMA·Class I 면제)와 공공보험 급여 등록 / 식품·제약 FDA·cGMP·약전 등급 / 전기·무선기기 FCC·UL / 작업장 안전 OSHA / 항공 FAA / 원자력·방산 NRC·ITAR / 개인정보·보안 HIPAA·CCPA·주별 생체정보 보호법·SOC 2.
- **미국 경쟁사**: 해당 분야 미국 선도기업 실명 2~3개를 들고 차별 근거·가격 우위를 묻는다.
- **미국 첫 고객·파이프라인**: "미국 기업의 구매 의사결정자와 인터뷰했는가", "미국 고객 파이프라인이 실제로 있는가".
- 상세 패턴은 `judge_questions_texcore.md` 1-5절·2절.
