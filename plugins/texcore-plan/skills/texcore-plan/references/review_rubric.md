# 모의심사 루브릭 — 텍스코어 실제 평가표 기준 5인 패널 + 검산 (tp-panel)

> 실제 심사: 5인이 신청서·5분 영상을 사전검토하고 의견서(강점·약점·보완사항·질의사항)를 쓴 뒤 점수를 낸다. 최종 선정은 평가위원 점수 산술평균 고득점순(안내서 p.8)이고 하네스 목표선은 합계 80점이다. **후하게 주지 않는다.** 캘리브레이션 데이터는 `judge_calibration.md`(공개판은 일반화된 기준. 내부 캘리브레이션 자료가 있는 환경은 설치 시 같은 파일명으로 덮어쓴다).

## 3. 심각도
- **critical**: 출처 없는 핵심 숫자(시장·효과·비용) / 앞뒤 숫자 충돌 / 질문에 답하지 않는 칸(X) / 가격·지불 주체 없음 / 팀 표 공란 / 권리관계 표 비어 있음 / 활동 목록식 일정(◆ 없음) / 시제품 성공 기준 없음 / 인증 필요한 분야인데 인증 일정 없음 / 해외형인데 미국 시장 언급 없음 / 금지 표현 잔존 / 자격 요건 위반(EL·PM 소속 불일치 등)
- **major**: 산식 미표기 / 라벨([추정]·[목표]) 누락 / 근거 1개뿐인 시장·문제 / 전문 용어 미설명 / 경쟁표에 우리 약점 없음 / 첫 고객 실명 없음 / 그림에 캡션·출처·증명 없음 / 세 문장 공식 중 하나가 기술 이름으로 시작 / TRL 증거 없음
- **minor**: 문장 길이 / 중복 표현 / 단위 표기 불일치 / 소제목이 질문의 답이 아님

## 4. 섹션 O/△/X
- O: 결론 박스가 질문의 답이고 증거 그림·표에 숫자·출처가 있다
- △: 답은 있으나 근거가 [추정]·[확보 필요]에 의존하거나 출처 1개 이하
- X: 답이 없거나 [자료 없음]·[기입 필요]가 남아 있다

## 5. 채점 요령
- 항목 점수는 만점 조건 대비 충족 비율로. 20점 항목에서 12점 이하는 "그 칸을 읽고 무엇을 하는지 모르겠다" 수준. 캘리브레이션: 상위권 팀도 핵심기술·참여의지에서 만점을 받지 못하는 것이 보통이다. 합계 70점대가 흔한 분포이고 80점 이상은 소수다.
- 의견서 4칸은 실제 양식 그대로 — 강점 2~3줄(숫자 인용), 약점 2~3줄, 보완사항 2~3줄(무엇을 어디에 추가), 질의사항 2줄.
- 공격 질문은 "실제 비대면 Q&A에서 던질 것" 3개. `judge_questions_texcore.md`의 유형을 따른다.
- 해외형 P/F: 영문 Summary가 없거나 미국 시장·규제·인터뷰 대상이 전혀 없으면 F.

## 6. chair 병합
- 5인 점수 평균(`scores.avg`) + 항목별 점수는 5인 중앙값(`item_scores`), 섹션 판정은 가장 낮은 것, issues 중복 병합(id `C01/M01/m01`), numbers_check의 충돌·오계산·출처 없음은 critical/major로 편입, 공격 질문 15개로 압축, 의견서 4칸 병합, `readability`(전문 용어 목록·긴 문장 수·판정), "85점 이상 받으려면" 처방 5~8개(어느 섹션에 무엇을 추가·삭제).
