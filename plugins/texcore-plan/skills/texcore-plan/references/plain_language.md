# 쉬운 언어 규칙 — 심사위원이 한 번 읽고 이해하는 단어·문장 (tp-writer 필수, tp-panel layman 채점 기준)

> 심사위원 5인 중 해당 분야 전문가는 0~1명이다. 전문가도 한 팀에 쓰는 시간이 짧다. **한 번 읽고 이해 못 하면 그 문장은 없는 문장**이다.

## 1. 문장 규칙
1. **한 문장 = 한 사실.** 80자 이내(validate lint). 두 가지 말을 하려면 두 문장.
2. **주어 → 숫자 → 결과** 순서. "재활병원 치료사 1명이 환자 1명을 세우는 데 20분이 걸립니다." (❌ "재활 현장에서는 보행 훈련 시 다수의 인력이 소요되는 문제가 존재합니다.")
3. 첫 문장이 결론. 배경 설명은 결론 뒤에 1~2문장만.
4. 능동태·현재형. "~됩니다/~되어집니다/~할 것으로 사료됩니다" 금지 → "~합니다/~입니다".
5. 명사 나열("…의 …의 …") 3단 이상 금지. 풀어서 쓴다.
6. 한 문단에 접속사 "또한·그리고·아울러·한편" 2회 이상 금지 → 불릿으로.
7. 괄호 속 보충은 1개까지. 괄호 안에 또 괄호 금지.

## 2. 단어 규칙 — 전문 용어는 "일반 명사 + (전문어)" 또는 "전문어(한 줄 설명)"
| 대신 | 이렇게 |
|---|---|
| 임피던스 제어 알고리즘 | 환자가 미는 힘에 맞춰 로봇이 힘을 조절하는 제어(임피던스 제어) |
| NASICON 기반 전기투석 | 전기로 소금물에서 불순물을 걸러 순도 99.99%를 만드는 세라믹 막(NASICON) |
| TRL 4 | 연구실 환경 테스트 단계(TRL 4) — 양식의 9단계 명칭을 그대로 병기 |
| SLAM | 카메라만으로 자기 위치를 아는 기술(SLAM) |
| PoC / MVP | 시험 적용(PoC) / 핵심 기능만 담은 첫 제품(MVP) |
| B2B·B2G | 기업 고객·공공기관 고객 — 처음 한 번은 풀어 쓰고 이후 약어 |
| CAGR 23% | 해마다 23%씩 성장(연평균 성장률) |
- 영문 약어는 **첫 등장에 한국어 설명을 먼저**, 괄호에 약어. 이후엔 약어만.
- 수식·화학식·모델명은 Ⅱ-1 기술 덩어리 설명에만, 그것도 한 줄에 하나.
- 단위는 한국 관행으로: 억 원·만 원·명·건·개월. 달러는 원화 병기(환율 기준 표기).
- "약", "다수", "상당한", "많은" 대신 숫자. 숫자가 없으면 `[기입 필요]`.

## 3. 이중 언어 전략 (biz-mentor)
- **문제·고객·의미·시장·일정**: 일반 언어(비전문 심사위원이 5초에 공감). 비유 허용: "당신의 부모님이 자다가 쓰러지지 않게 하는 것".
- **핵심기술 덩어리 이름·증거(특허번호·논문·시험 조건·P값)**: 정확한 전문 용어(전문가 심사위원에게 신뢰 신호). 단 덩어리마다 "기능 한 줄(쉬운 말)"을 먼저 쓴다.
- 한 칸 안에서 두 언어를 병치한다: `[쉬운 말 한 줄] — [정확한 용어·수치 한 줄]`.

## 4. 심사위원이 5초에 읽게 하는 장치
1. 섹션 첫 블록 **결론 박스(callout)**: 질문의 답 + 숫자.
2. 소제목은 **질문의 답이 보이게**: "□ 목표 고객" 대신 "□ 목표 고객 — 회복기 재활병원 46곳의 치료사".
3. 불릿은 **굵은 머리말 + 한 줄**: "구매 결정자: 병원장(장비 구매 승인), 사용자: 치료사(하루 8명)".
4. 표의 첫 열은 심사위원 질문(비교 기준), 마지막 열은 "우리에게 의미".
5. 그림 캡션 아래 **"→ 증명: …"** 한 줄(이 그림이 무엇을 입증하는지).
6. 숫자는 비교와 함께: "8분 → 40초(12배)". 혼자 있는 숫자는 의미가 없다.

## 5. 생성 티(AI 냄새) 제거 체크 (KoEF 교안 '제출 전 AI 함정')
- "혁신적·차별화된·다각도·시너지·패러다임·최적의·원스톱" 전수 삭제(banned_phrases).
- 같은 문장 구조 3연속 금지("~을 통해 ~을 제공합니다" 반복).
- 모든 문단에 **우리 실험실·우리 팀·우리 고객의 고유명사**가 1개 이상(없으면 어느 팀 신청서에나 붙는 문장).
- 추상 고객("다양한 산업", "일반 소비자") 금지 → 이름·소속·상황이 보이는 1명(페르소나).

## 6. 영문(Summary) 쉬운 영어
- 한 문장 20단어 이내, 능동태. 전문어는 괄호 설명. 미국 고객이 쓰는 명사(outpatient rehab clinic, warehouse operator)로.
- 숫자·비교 대상 실명 포함. "innovative, cutting-edge, world-class" 금지.
